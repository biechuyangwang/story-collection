## 组合建议

- **「坚持」主题**：铁杵磨成针 → 王羲之与墨池 → 毛竹的秘密，从「下功夫」讲到「耐得住寂寞」。
- **「勇气」主题**：小鹰学飞 → 爱迪生和第一千零一次实验，一个讲敢试，一个讲败了再来。
- **「基本功」主题**：达·芬奇画鸡蛋 → 熟能生巧（成语故事）→ 邓亚萍的一万次挥拍，跨分类连讲。
- **「命运的答卷」组合**（适合大孩子）：海伦·凯勒 → 贝多芬 → 刘伟，三人和命运正面交手，全都赢了。
- **「身边的了不起」组合**：屠呦呦 → 邓亚萍 → 刘伟，都是当代中国人，孩子更容易有代入感。
