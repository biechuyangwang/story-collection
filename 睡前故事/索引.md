## 推荐睡前连播顺序

1. **月亮主题之夜**：嫦娥奔月 → 玉兔捣药（讲完正好指着窗外月亮说晚安）
2. **星空主题之夜**：牛郎织女 → 星星银元 → 女娲造人
3. **温柔力量之夜**：北风与太阳 → 狮子与老鼠 → 蚂蚁与鸽子
4. **小聪明之夜**：乌鸦喝水 → 龟兔赛跑 → 城里老鼠和乡下老鼠
5. **软软的梦之夜**：甜粥 → 豌豆公主 → 不莱梅的音乐家（吃饱、睡暖、有人陪）
6. **睡个好觉之夜**：睡美人 → 豌豆公主（全世界都在陪她安睡）
7. **世界从哪里来之夜**：盘古开天 → 女娲造人 → 仓颉造字（适合第一次问"世界怎么来的""字是从哪来的"的孩子）
8. **别轻信之夜**：狐狸和乌鸦 → 磨坊主、儿子和驴
9. **了不起的人之夜**：夸父追日 → 神农尝百草 → 大禹治水
