## 数据管线

改故事后依次运行：

```bash
python3 _regen_indexes.py   # 按磁盘重建各分类索引.md
python3 build_site.py       # 生成 docs/data.json（前端数据）
git add -A && git commit && git push   # Pages 自动部署
```

其他工具：`_quote_convert.py --dry`（引号规范自查）、`_fetch_geo_images.py`（地理图片检索下载，Commons 开放授权）。

## 收录与写作规范

- 不逐字照抄有版权的译本与文章；童话 / 寓言为睡前改编版；短篇小说与名著导赏仅收录**公有领域**原著，片段为编译改写并注明。
- 全库引号统一：对话“”、特指「」、内层‘’；新篇写完用 `_quote_convert.py --dry` 自查。
- 每篇体例：信息行（出处 / 适读年龄 / 朗读时长）+ 正文 + 结尾段（「晚安小结」或「小启示」）。
- 地理分类新增地标：在 `_fetch_geo_images.py` 加词条下载图片（Commons 开放授权），**逐张目检**后在 `中国国家地理/图片版权.md` 登记署名。
