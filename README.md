## 睡前故事收录标准

一篇故事适合做睡前故事，应满足：

1. **基调温柔**：没有恐怖、暴力或令人不安的情节，冲突温和，有圆满收尾。
2. **篇幅适中**：朗读 3~5 分钟（约 600~1000 字），孩子听着听着自然入睡。
3. **节奏舒缓**：结尾安静、有睡意，最好落在月亮、星星、晚安等意象上。
4. **寓意正面**：善良、友爱、诚实、坚持等，说完还能轻声聊两句。

每篇故事文件统一包含：

- 开头的信息行：出处、适读年龄、朗读时长
- 正文（口语化，适合直接朗读）
- 结尾的「晚安小结」：给家长的一句话，方便读完轻声收尾

## 成语故事 / 励志故事 / 反转故事收录标准

三个分类以「听得懂、有收获」为准，不要求睡前式的舒缓结尾：

1. **篇幅**：单篇 3~5 分钟，口语化，适合朗读。
2. **讲清楚**：成语故事要交代来龙去脉，开头注明成语含义和典籍出处；励志故事注明人物与事迹来源；反转故事要求结尾「意料之外、情理之中」，反转落下后能回味出温度或道理。
3. **有收获**：结尾用一段「小启示」点明道理，家长可以照着和孩子聊两句；反转故事涉及离别等沉重情节的，在索引中注明共读建议。

文件格式：信息行 → 正文 → 「小启示」。

## 电台故事收录标准

电台故事面向**大人的心理按摩**（情绪疗愈、晚安陪伴），与其他儿童向分类的定位区分开：

1. **电台节目体**：固定三段式——「开播的话」（用第二人称把听众带进来）→「今晚的故事」（一个温柔的比喻性小故事）→「收音前的话」（点题、给出可做的小动作）。
2. **口吻**：深夜 FM 的陪伴感，语速提示、配乐建议写在开头的信息行里。
3. **主题**：聚焦情绪疗愈——放下、接纳、慢下来、清空烦恼、情绪流通、自我关怀等，一期只治一个「心里的小毛病」。
4. **篇幅**：每期朗读约 5 分钟，结尾统一收在「晚安」上。

## 节日故事收录标准

按节日组织「故事包」，节前连播应景：

1. **组成**：每个节日 3~4 篇，从「天上 / 由来」讲到「桌上 / 习俗」，优先复用其他分类中已有的应景篇目，新写补充缺口的。
2. **格式**：信息行 → 正文 → 「节日小卡片」（一句话讲清节日日期与习俗，方便边读边讲）。
3. **基调**：延续睡前故事的温柔标准，节日夜可直接当睡前故事用。

## 网站与部署

故事库配有静态前端，已通过 GitHub Pages 发布：

**在线阅读**：https://biechuyangwang.github.io/story-collection/

功能：分类浏览（含子分类）、全文搜索、日间/夜读双主题（睡前场景默认夜读色）、字号调节、网页朗读（浏览器 TTS）、上下篇切换。手机端自适应。

## 打印版合集

`合集打印版/` 存放从故事库导出的整册文档（如亲子朗读手册），方便打印装订。故事源文件始终以各分类目录下的 Markdown 为准。

## 前端构建与发布流程

```
python3 build_site.py        # 扫描全部 Markdown → docs/data.json
python3 -m http.server 8642  # 本地预览 http://localhost:8642
git add -A && git commit -m "..." && git push
```

推送到 `main` 后，GitHub Pages 自动重新发布（约 1 分钟生效）。前端本体是 `index.html` + `assets/`（原生 HTML/CSS/JS，无框架；marked.js 已本地化到 `assets/vendor/`）。
